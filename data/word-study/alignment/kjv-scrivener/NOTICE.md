# Scrivener 1894 parsed Greek witness

The Greek token data derives from [Honza Pokorny's machine-readable Scrivener 1894 transcription](https://github.com/honza/textus-receptus/tree/2bac2dae4a0961c84d6d544a40cbef8b8d8c4e32). The pinned notice permits unrestricted use of data files. The repository's software carries a separate GPL license. GOD4.us uses the data and its own compiler.

Word groups derive from the pinned CrossWire KJV OSIS. GOD4.us verified each group against the exact displayed English and the complete ordered Scrivener token sequence, Strong's identifiers and morphology. The importer removes terminal punctuation from the original token surfaces and excludes supplied English groups. The [publication report](../../../../docs/shell-84-scrivener-publication.json) records the input and output SHA-256 checksums.
